# RTP Ledger

[RTP Ledger](https://rtpledger.com) publishes slot RTP (return to player) data with sources: provider-published RTP values, multiple-RTP-version flags and last-checked dates.

- Slot RTP database: https://rtpledger.com
- Slots with multiple RTP versions: https://rtpledger.com/slots/multiple-rtp-versions

The game's own info panel is always the final reference. 18+. Gambling involves risk.
